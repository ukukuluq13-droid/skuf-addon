# ПГТ / Деревенский Покой — измерение (пример датапака)

Финал ArthurTech (§23.2–23.3): не бесконечный рост завода, а **право его выключить**. ПГТ —
тихое мирное измерение «Деревенский Покой».

Согласно концепту (D12 / §23.3), измерение — **самый дорогой и опциональный блок**, поэтому делается
**модпак-сайд датапаком**, а не dimension-логикой в jar аддона. Аддон даёт лишь предмет-ключ:
`skufaddon:item_derevenskiy_pokoy_singularity` (крафтится в финале, см. `SkufRecipes.finaleChain`).

## Что внутри (`pgt_derevenskiy_pokoy/`)
Минимальный рабочий пример измерения `skufaddon:pgt`:
- `dimension_type/pgt.json` — тип измерения: фиксированный полдень (`fixed_time: 6000`),
  монстры не спавнятся (`monster_spawn_light_level: 0`), есть небо, мирно и тихо;
- `dimension/pgt.json` — генератор: стандартный overworld-шум + фиксированный биом `plains`
  (спокойный ландшафт без хаоса).

Это **намеренно простой каркас** под идею «меньше потеть». Модпак может заменить биом/генератор
на свой (деревенский хаб, пассивная генерация ресурсов, НПС «Добрые дяди» и т.д.).

## Как подключить
1. Положи папку `pgt_derevenskiy_pokoy/` в `datapacks/` нужного мира (или раздай через модпак).
2. `/reload` (или перезаход в мир).
3. Телепорт в ПГТ — модпак-сайд: привяжи к ключу-предмету. Пример команды:
   ```
   /execute in skufaddon:pgt run tp @s 0 120 0
   ```
   Боевую привязку «использовал Сингулярность → открылось измерение» удобно повесить через
   KubeJS/командный блок на стороне модпака (это и есть «датапак + ключ-предмет» из концепта).

## Заметка
Поведение стазиса (Капсула «Лирика в Падике») и реальная «победная» механика входа в ПГТ
завязаны на ауру/тильт — это домен друга. Здесь дан рабочий каркас измерения и предмет-ключ.
