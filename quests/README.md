# Квест-книга ArthurTech (FTB Quests)

Главный внутриигровой гайд по аддону — датапак **FTB Quests**. Согласно концепту (§7), квест-книга
живёт на стороне **модпака**, а не в jar аддона: аддон лишь даёт предметы-гейты (`skufaddon:item_*`),
на которые завязаны главы.

## Куда класть
Скопируй содержимое `ftbquests/` в папку мира (или дефолтных конфигов модпака):

```
<инстанс>/saves/<мир>/ftbquests/quests/        ← для существующего мира
<модпак>/config/ftbquests/quests/              ← как дефолт модпака (kubejs/overrides)
```

После запуска FTB Quests подхватит книгу. ID квестов уникальны; при желании можно
перегенерировать/доработать в режиме редактора (гаечный ключ → Edit Mode).

## Содержание (10 глав, §7)
| Глава | Название | Цель | Тон |
|---|---|---|---|
| 0 | Перед тем как всё стало жижей | Понять, что мир деградировал | Коротко, грязно |
| 1 | Грязный двор | Первые жидкости и пыль | «Дроби камень, делай вид, что это прогресс» |
| 2 | Нормисный фильтр | Очистка ресурсов | «Фильтруй не людей, а жижу. Пока что» |
| 3 | ЧПУ станкчанин | LV-цепочка точности → Правильная Вещь | «Станок честнее позы» |
| 4 | Разрабская неоднозначность | Стабильная разрабская схема | «Работает — не трогай» |
| 5 | Вайб и похуизм | Стабилизированный вайб | «Система ломается, но уже не у тебя» |
| 6 | Челябинский Провал | Первый крупный мультиблок | «Счётчик трещит, но процесс идёт» |
| 7 | Дискорд всё | Логистика и сеть | «Нет маршрута — нужен роутер» |
| 8 | Конец культуры | Нормисная сингулярность + капсула стазиса | «Разделяй центрифугой» |
| 9 | Абсолютный похуизм | Абсолютный Похуит → мейнфрейм → Деревенский Покой | «Теперь можно не объяснять» |

Награды — опыт (XP) на каждый квест + предметы на ключевых вехах (C9). Тон — мем-слэнг (C10).

## Заметки
- Задачи завязаны на стабильные `skufaddon:`-предметы (предметы, вёдра, корпус) — их ID не поменяются.
- Шаги «построй машину/мультиблок» оформлены чек-марками, чтобы не зависеть от внутренних ID
  блоков-машин GTCEu (они отличаются по версиям). При желании замените на item-таски на блоки машин.
- Финал главы 9 (Деревенский Покой) — ключ измерения ПГТ; само измерение открывается
  модпак-сайд датапаком (см. `../datapacks/`).
